The design representation for software systems. Humans author it. Agents compile it.

intent-specs capabilities · constraints

ux-specs mockups · views · interactions
system-specs containers · components · interfaces

The design does four jobs at once.

EDITED BY HUMANS
Smaller than the code. Tens of items, not thousands.
CHECKED BY AGENTS
Verification ladder: decidable structural · mechanical runners · heuristic eval.
SHARED ACROSS RUNS
Persistent across sessions, models, contributors. The next agent inherits.
EVAL EVERY OUTPUT
Every generated artifact verified against approved upstream truth.

Storey (Canada Research Chair, Mar 2026) named the missing object: intent debt — the absence of externalized rationale developers and AI agents need to work safely with code. The codæ contract is that externalized intent. VibeLoom is the reference implementation.
